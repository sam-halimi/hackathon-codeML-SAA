# Boussole

**On vous accompagne, pas à pas.** Une application qui guide une personne victime d'agression sexuelle à Montréal : où aller, qui peut l'écouter, comment raconter une seule fois, et, si elle le décide, comment monter un dossier pour un service juridique. L'IA guide, l'humain décide.

Défi : Propolys, *Startup Challenge : Sécurité & IA*. Livrable : pitch de 3 minutes et 3 diapositives.

| Dossier | Contenu |
|---|---|
| [`app/`](app/) | Application (bêta de test, données fictives) : https://boussole-beta.vercel.app |
| [`pitch/`](pitch/) | `PITCH.md` (script et sources), `SLIDES.md`, `VIDEO.md`, `deck/` (PowerPoint + générateur), `assets/` (QR code, captures, articles, vidéos rendues) |
| [`video/`](video/) | Projet Remotion des clips de démo |

Garde-fous : aucune désignation de coupable, aucun score de crédibilité, aucune reconnaissance faciale ; consentement à chaque étape ; données chiffrées sur l'appareil ; envoi au service juridique simulé en bêta.
